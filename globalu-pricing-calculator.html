The cost of late changes

Pre-production changes cost nothing. The same changes made after build begins can cost thousands. This is the single strongest commercial argument for investing in a thorough pre-production phase.

Change type If caught in pre-production If caught post-build Why it costs more post-build
Script / narration edit £0 — text change in Word £200 – £2,000+ Requires re-render in ElevenLabs, re-sync in Storyline or Rise, re-QA of audio timing, and potential layout adjustments.
Learning objective change £0 — revision to brief £500 – £5,000+ May invalidate multiple screens, interactions, and assessments. Cascades through storyboard, build, and QA phases.
Scenario / branching restructure £0 — update to storyboard £1,000 – £8,000+ Storyline variables, triggers, and branching logic must be rebuilt. All affected audio re-rendered and re-synced.
Brand / visual style change £0–£200 — update template £800 – £3,000+ Every built slide or Rise block must be updated. Custom animations, character states, and graphics may all need rework.
Factual / accuracy correction £0 — script update before build £200 – £1,500+ Text, audio, and any related graphics or interactions must all be updated and re-tested in the LMS.
